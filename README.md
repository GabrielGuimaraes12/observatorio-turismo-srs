# Observatório do Turismo de Santa Rita do Sapucaí

Plataforma Web desenvolvida para o Observatório do Turismo de
Santa Rita do Sapucaí no projeto HEIComp 2026.2 - Inatel.

## Tecnologias

### Front-end
- React
- TypeScript
- Vite

### Back-end
- Node.js
- NestJS
- TypeScript
- Prisma ORM

### Banco de Dados
- PostgreSQL
- Docker Compose

## Pré-requisitos

Antes de executar o projeto, instale:

- Git
- Node.js
- Docker Desktop
