# Frontend do Observatório

Consulte o [guia de instalação do projeto](../README.md) para configurar o
PostgreSQL e a API, instalar as dependências e iniciar o portal.

Nesta pasta, `npm test` executa os testes do frontend e `npm run build`
gera os arquivos estáticos em `dist/`. Para testar o portal e a API juntos,
siga o [guia de testes ponta a ponta](../docs/testes-e2e.md).
